# 제작 워크플로우

## 1. 기획

각 프로젝트는 `00_brief.md`에서 시작합니다. 이 문서에는 영상의 목적, 시청자, 플랫폼, 예상 길이, CTA, 금지 표현을 기록합니다.

## 2. 스크립트 작성

`01_script/script.md`에는 사용자가 그대로 읽을 수 있는 문장만 작성합니다. 편집 메모는 본문에 섞지 않고 `01_script/script_notes.md`에 따로 기록합니다.

권장 형식은 다음과 같습니다.

```text
[00:00-00:05]
오늘은 ○○를 가장 쉽게 이해하는 방법을 알려드릴게요.
```

## 3. 음성·원본 파일 수집

사용자가 녹음한 mp4 또는 오디오 파일은 `02_voice/`에 저장합니다. 별도로 전달된 화면 녹화, 참고 영상, B-roll은 `03_raw_video/`에 저장합니다.

파일명은 아래 규칙을 따릅니다.

```text
YYYY-MM-DD_project-slug_voice_take01.mp4
YYYY-MM-DD_project-slug_reference01.mp4
```

## 4. 씬 분해

`05_hyperframe/edit_plan.md`에서 내레이션을 씬 단위로 나눕니다. 각 씬에는 다음 항목이 있어야 합니다.

- 타임코드
- 내레이션 요약
- 씬의 목적
- 화면 레이아웃
- 등장 오브젝트
- 모션 지시
- 자막 스타일
- 전환 효과
- 필요한 에셋

## 5. Hyperframe 편집

Hyperframe 편집 시 얼굴이 들어간 원본 영상은 직접 노출하지 않습니다. 필요한 경우 음성 파형, 텍스트 카드, 캐릭터 실루엣, 제품 이미지, 도형 애니메이션, 데이터 시각화로 대체합니다.

## 6. 검수와 출력

초안 출력물은 `06_exports/draft/`, 최종 출력물은 `06_exports/final/`에 저장합니다. 피드백은 `07_review/feedback.md`에 날짜별로 기록합니다.
