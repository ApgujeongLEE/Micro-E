# Hyperframe 편집 스타일 가이드

## 화면 스타일

- 기본 비율: Shorts/Reels/TikTok은 9:16, YouTube 일반 영상은 16:9로 설정합니다.
- 배경: 단색 그라디언트, 종이 질감, 추상 패턴 중 하나를 사용합니다.
- 인물 대체 표현: 얼굴 대신 실루엣, 아바타 뒷모습, 손 아이콘, 음성 파형, 말풍선을 사용합니다.
- 정보 전달: 핵심 단어는 큰 타이포그래피, 숫자는 카운터 애니메이션, 과정은 단계형 카드로 보여줍니다.

## 모션 규칙

- 도입 3초 안에 큰 움직임을 넣어 이탈을 줄입니다.
- 씬 전환은 0.2~0.5초의 짧은 wipe, push, zoom, blur를 우선 사용합니다.
- 중요한 문장은 키워드가 한 단어씩 튀어나오는 kinetic typography로 표현합니다.
- 설명형 구간은 아이콘 3개 이하와 짧은 화살표 모션으로 단순화합니다.

## 자막 규칙

- 한 화면 자막은 최대 2줄로 제한합니다.
- 강조 단어는 색상 또는 굵기로 표시하되, 한 문장에 1~2개만 강조합니다.
- 자막은 음성보다 0.1초 빠르게 등장하고, 음성이 끝난 뒤 0.2초 후 사라지게 설정합니다.

## 얼굴 비노출 규칙

- 사용자가 전달한 mp4에 얼굴이 포함되어 있으면 원본 화면은 사용하지 않습니다.
- 손, 책상, 물건 등 얼굴이 없는 부분만 크롭해서 사용할 수 있습니다.
- 얼굴이 필요한 맥락은 추상 아바타, 실루엣, 아이콘, 텍스트 중심 구도로 대체합니다.
