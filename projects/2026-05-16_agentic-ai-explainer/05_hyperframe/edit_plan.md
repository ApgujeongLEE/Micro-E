# Hyperframe 편집 계획서: Agentic AI 1분 설명

## 프로젝트 설정

- 화면 비율: 9:16
- 해상도: 1080x1920
- 프레임레이트: 30fps
- 예상 길이: 60~63초
- BGM: 저음이 약한 테크 미니멀 루프, 음성보다 -18~-22 LUFS 수준
- 자막 폰트: Pretendard 또는 Noto Sans KR Bold
- 메인 컬러: #7C5CFF 보라
- 보조 컬러: #00D1FF 시안, #F6F7FB 화이트

## 전체 콘셉트

- 얼굴 노출 없이 `질문 → 차이 → 예시 → 작동 루프 → 통계 → 안전장치 → 전망` 순서로 전개합니다.
- 시각 언어는 “AI가 생각하고 실행하는 흐름”을 보여주는 노드, 카드, 화살표, 체크리스트, 숫자 카운터입니다.
- 모든 통계는 화면 하단에 작은 출처 라벨을 넣습니다.

## 통계 시각화 지시

### S05: 75% 링 차트

- 출처 라벨: `Source: Gartner survey, 2025`
- 내레이션의 “75%”와 동시에 숫자가 0에서 75까지 카운트업됩니다.
- 링 차트는 3/4 지점까지 채우고, 배경에는 기업 빌딩 아이콘 10개 중 8개를 밝게 켭니다.

### S06: 15% 파이 차트

- 출처 라벨: `Source: Gartner survey, 2025`
- 밝은 파이 조각은 15%만 표시하고, 나머지 85%는 회색으로 남깁니다.
- 메시지가 비관적으로 보이지 않도록 방패 아이콘과 체크 아이콘을 함께 배치합니다.

### S07: 2028년 33% 전망 바 그래프

- 출처 라벨: `Source: Gartner prediction`
- 2024년 막대는 `less than 1%`, 2028년 막대는 `33%`로 표시합니다.
- 막대 그래프 위에는 작은 소프트웨어 창 아이콘들이 차례로 켜지는 모션을 넣습니다.

## 얼굴 비노출 처리

- 사용자가 전달한 녹음 mp4에 얼굴이 포함되어 있어도 화면에는 직접 사용하지 않습니다.
- 음성만 내레이션으로 사용하고, 말하는 사람의 존재감은 음성 파형, 노드 pulse, 자막 리듬으로 대체합니다.
- 손이나 데스크 장면을 사용할 경우 얼굴·신체 식별 정보가 보이지 않도록 강하게 크롭합니다.

## Hyperframe 작업 순서

1. `02_voice/`에 녹음 파일을 넣고 음성을 타임라인에 배치합니다.
2. 실제 음성 길이에 맞춰 S01~S08 타임코드를 ±1초 범위에서 조정합니다.
3. 자막을 먼저 배치하고, 강조 단어 `목표`, `실행`, `75%`, `15%`, `33%`에 색상 포인트를 줍니다.
4. S04 루프 다이어그램과 S05~S07 통계 그래픽을 먼저 제작합니다.
5. BGM과 효과음을 낮게 깔고, 숫자 카운트업 순간에만 tick/pop 효과음을 사용합니다.
6. 전체 타임라인에서 얼굴 노출, 출처 라벨, 자막 오탈자를 확인합니다.
7. 초안은 `06_exports/draft/`, 최종본은 `06_exports/final/`에 출력합니다.
