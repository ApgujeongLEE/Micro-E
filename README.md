# Hyperframe 모션 영상 프로젝트 관리 템플릿

이 저장소는 Hyperframe을 사용해 **얼굴 노출 없이 모션 애니메이션 기반 영상**을 제작하기 위한 다중 프로젝트 관리 구조입니다. 여러 영상 프로젝트를 동시에 진행해도 스크립트, 음성 녹음본, 원본 영상, 에셋, Hyperframe 편집 지시서, 최종 산출물이 섞이지 않도록 설계했습니다.

## 폴더 구조

```text
Micro-E/
├─ docs/                         # 전체 제작 방식과 편집 규칙
├─ scripts/                      # 새 프로젝트 생성 자동화 스크립트
├─ templates/project-template/    # 모든 프로젝트가 복사해서 쓰는 표준 템플릿
├─ projects/                     # 실제 영상 프로젝트들이 들어가는 위치
└─ shared_assets/                # 여러 프로젝트가 함께 쓰는 공용 에셋
```

## 기본 진행 방식

1. `templates/project-template`을 복사해 `projects/YYYY-MM-DD_project-slug` 형식의 새 프로젝트를 만듭니다.
2. `01_script/script.md`에 읽을 스크립트를 작성합니다.
3. 사용자는 스크립트를 읽고 음성을 녹음한 뒤 `02_voice/`에 mp4 또는 오디오 파일을 넣습니다.
4. 전달받은 영상 또는 음성 파일은 `03_raw_video/`에 보관합니다.
5. `05_hyperframe/edit_plan.md`에 씬별 타임코드, 화면 구성, 모션, 자막, 전환 효과를 명시합니다.
6. Hyperframe에서 얼굴 노출 없이 추상 모션, 캐릭터 실루엣, 타이포그래피, 아이콘, 인포그래픽 중심으로 편집합니다.
7. 최종본은 `06_exports/`에 저장하고, 피드백은 `07_review/`에 기록합니다.

## 새 프로젝트 만들기

```bash
./scripts/new_project.sh my-first-video
```

위 명령은 `projects/YYYY-MM-DD_my-first-video` 폴더를 만들고 표준 템플릿을 복사합니다.

## 프로젝트별 핵심 문서

| 파일 | 목적 |
| --- | --- |
| `00_brief.md` | 주제, 대상 시청자, 톤, 길이, 핵심 메시지 정의 |
| `01_script/script.md` | 사용자가 실제로 읽을 내레이션 스크립트 |
| `05_hyperframe/edit_plan.md` | 씬별 편집 계획, 타임코드, 모션 지시 |
| `04_assets/asset_list.md` | 필요한 이미지, 아이콘, 음악, 효과음 목록 |
| `07_review/feedback.md` | 수정 요청과 반영 여부 추적 |

## 편집 원칙

- 얼굴이 드러나는 장면은 사용하지 않습니다.
- 말하는 사람의 존재감은 파형, 자막, 실루엣, 손동작 아이콘, 추상 오브젝트로 대체합니다.
- 모든 씬은 내레이션 기준으로 시작·종료 시간을 먼저 정한 뒤, 화면 요소와 모션을 배치합니다.
- 씬마다 `목적`, `화면 구성`, `모션`, `자막`, `전환`을 반드시 작성합니다.
