## 얼굴 비노출 처리

- 원본 mp4에 얼굴이 포함되어 있으면 화면에는 사용하지 않습니다.
- 음성은 내레이션으로만 사용하고, 말하는 사람은 파형 또는 추상 아바타로 표현합니다.
- 손이나 사물 장면을 사용할 경우 얼굴이 보이지 않도록 크롭합니다.

## Hyperframe 작업 순서

1. 음성 파일을 타임라인에 먼저 배치합니다.
2. 음성 파형 기준으로 씬 타임코드를 확정합니다.
3. 각 씬에 배경과 주요 오브젝트를 배치합니다.
4. 자막을 음성보다 0.1초 빠르게 배치합니다.
5. 씬 전환과 효과음을 추가합니다.
6. 얼굴 노출 여부를 전체 타임라인에서 다시 확인합니다.
7. 초안 mp4를 `06_exports/draft/`에 출력합니다.
